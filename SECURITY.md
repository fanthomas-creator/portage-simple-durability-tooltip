# Security policy

Native mods run with the game's permissions. Install only packages from sources you trust and verify the minisign signature using the expected project public key.

Do not publish credentials, private signing material or personal player data in issue reports. If a public repository is created, use its private vulnerability-reporting feature when enabled. Until then, contact the maintainer privately rather than posting sensitive details publicly.

Security fixes should state affected versions and exact validation. Keep private keys outside the source tree; never provide signing keys to pull-request workflows.
