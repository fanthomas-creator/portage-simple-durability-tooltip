# Support

Read docs/USAGE.md first. A useful report includes port version, Horizon revision, Minecraft version, whether Advanced Tooltips is on, a damaged item's relevant non-sensitive component data, and a small screenshot or reproduction. Remove account names, server addresses, tokens and personal paths from logs before sharing them.

Report Rust-port issues at https://github.com/fanthomas-creator/portage-simple-durability-tooltip/issues. Do not report port-specific problems to the original author's tracker.
