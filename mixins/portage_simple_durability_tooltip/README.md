# portage-simple-durability-tooltip native bundle

Unofficial community Rust port of Infinidoge's Simple Durability Tooltip (MIT). ID: portage_simple_durability_tooltip, version 0.1.1. Original: https://github.com/Infinidoge/simple-durability-tooltip, revision 35cad4b42a6be409e92dedb2093b470f09052031.

Enable the mod in Options → Mods and hover over a damaged item in the inventory. Adds the game's translated durability line when Advanced Tooltips is off; skips unbreakable, hidden, empty and non-damageable items and avoids duplicates. No settings screen or background polling is added.

Requires a native-mod build integration and the exact revisions in horizon-native.json and horizon-mixin.toml. Remove the old simple_durability_tooltip 0.1.0 package before rebuilding with this ID. Package validation is not a complete game compatibility test.

Original creator: Infinidoge. Port maintainer: fanthomas-creator, prepared with Codex assistance. Original MIT license and Horizon's MIT notice are included. The original creator does not maintain this port.
