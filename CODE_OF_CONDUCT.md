# Code of conduct

Be respectful, constructive and specific. Critique code and behavior rather than people. Harassment, discrimination, threats, doxxing, spam and attempts to obtain credentials or private signing keys are not welcome.

Respect the original authors and their licenses. Do not impersonate the original mod's author, Horizon maintainers or this project's maintainer.

The maintainer may edit or remove disruptive content, close off-topic issues and restrict participation. Decisions should be proportionate to the behavior. For sensitive reports, use GitHub's private reporting facilities when available; do not post private personal information in an issue.

This policy applies to issues, pull requests, reviews, discussions and other project spaces.
